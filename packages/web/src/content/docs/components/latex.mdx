# LaTeX

Render common LaTeX math formulas in the terminal. `@opentui/latex` provides a standalone `LatexRenderable` and an opt-in Markdown transform for `MarkdownRenderable`.

Install the LaTeX package separately:

```bash
bun install @opentui/latex
```

## Basic Usage

### Renderable API

```typescript
import { createCliRenderer } from "@opentui/core"
import { LatexRenderable } from "@opentui/latex"

const renderer = await createCliRenderer()

const formula = new LatexRenderable(renderer, {
  id: "cauchy",
  content: String.raw`f(a) = \frac{1}{2\pi i}\oint_{\gamma}\frac{f(z)}{z-a}\,dz`,
  width: "100%",
  align: "center",
  fg: "#f8fafc",
})

renderer.root.add(formula)
```

### Markdown Math

Markdown math is opt-in. Register the transform before creating `MarkdownRenderable` instances that should render formulas:

```typescript
import { MarkdownRenderable, SyntaxStyle } from "@opentui/core"
import { registerLatexMarkdown } from "@opentui/latex/markdown"

registerLatexMarkdown()

const markdown = new MarkdownRenderable(renderer, {
  content: String.raw`
Euler: $e^{i\pi} + 1 = 0$

$$
\frac{\sum_{i=1}^{n} x_i}{n}
$$

Inline code is ignored: \`$x_i$\`
`,
  syntaxStyle: SyntaxStyle.fromStyles({}),
})
```

The Markdown transform supports inline `$...$`, inline `\(...\)`, display `$$...$$`, and display `\[...\]`. Inline code and fenced code blocks are left unchanged.

`registerLatexMarkdown()` returns an unregister function. Calling it more than once reuses the existing registration.

### React JSX

```tsx
import { createRoot } from "@opentui/react"
import { registerLatex } from "@opentui/latex/react"

registerLatex()

createRoot(renderer).render(
  <latex content={String.raw`\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}`} align="center" fg="#f8fafc" />,
)
```

### Solid JSX

```tsx
import { render } from "@opentui/solid"
import { registerLatex } from "@opentui/latex/solid"

registerLatex()

render(() => <latex content={String.raw`\sqrt[3]{1 + \frac{x^2}{1 - x^2}}`} align="center" fg="#f8fafc" />)
```

## Supported Notation

The renderer supports a practical terminal subset of LaTeX math:

- fractions with `\frac{...}{...}`
- square roots and indexed roots with `\sqrt{...}` and `\sqrt[n]{...}`
- superscripts and subscripts
- Greek letters
- common relation, set, and logic symbols
- common operators such as `\sum`, `\prod`, `\lim`, `\int`, and `\oint`
- display-style limits for standalone formulas
- compact inline layout for Markdown inline math and fraction arguments
- common spacing commands such as `\,`

Unknown commands are rendered as their command name so unsupported input still produces visible output.

## Display and Inline Layout

Standalone `LatexRenderable` uses display layout. Large operators such as sums, products, limits, and integrals can use stacked limits when that makes the formula easier to read.

Markdown inline math uses compact layout:

```typescript
import { renderLatexToString } from "@opentui/latex"

const inline = renderLatexToString(String.raw`\frac{\sum_{i=1}^{n} x_i}{n}`, {
  layout: "inline",
})
```

Use display layout for formulas that should stand on their own:

```typescript
const display = renderLatexToString(String.raw`\lim_{h \to 0}\frac{f(x+h)-f(x)}{h}`, {
  layout: "display",
})
```

## Unicode and ASCII

Unicode mode is the default and gives the best output:

```typescript
const formula = new LatexRenderable(renderer, {
  content: String.raw`\alpha_i^2 + \beta_j^2 \le \gamma^2`,
  mode: "unicode",
})
```

Use ASCII mode when a terminal or font does not render Unicode math well:

```typescript
const formula = new LatexRenderable(renderer, {
  content: String.raw`\alpha_i^2 \le \frac{1}{2}`,
  mode: "ascii",
})
```

## Sizing and Fallback

`LatexRenderable` measures itself from the rendered formula. If the parent constrains the renderable too tightly, it clips the math by default. Provide `fallbackContent` to show compact fallback text instead:

```typescript
const formula = new LatexRenderable(renderer, {
  content: String.raw`\sqrt{1 + \frac{x^2}{1 - x^2}}`,
  width: 12,
  height: 1,
  fallbackContent: "formula",
  fallbackColor: "#94a3b8",
})
```

Use `align` to place formulas inside wider bounds:

```typescript
const formula = new LatexRenderable(renderer, {
  content: String.raw`\prod_{k=1}^{n}\left(1 + \frac{x}{k}\right)`,
  width: "100%",
  align: "center",
})
```

## Properties

| Property          | Type                            | Default     | Description                                       |
| ----------------- | ------------------------------- | ----------- | ------------------------------------------------- |
| `content`         | `string`                        | `""`        | LaTeX math source                                 |
| `mode`            | `"unicode" \| "ascii"`          | `"unicode"` | Output character set                              |
| `fg`              | `ColorInput`                    | white       | Formula foreground color                          |
| `bg`              | `ColorInput`                    | transparent | Formula background color                          |
| `attributes`      | `number`                        | `0`         | Text attributes passed to the terminal buffer     |
| `align`           | `"left" \| "center" \| "right"` | `"left"`    | Horizontal alignment inside the renderable bounds |
| `fallbackContent` | `string`                        | `""`        | Text to show when the formula does not fit        |
| `fallbackColor`   | `ColorInput`                    | white       | Fallback text color                               |
