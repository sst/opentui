# Quickstart

Build a small counter controlled by the arrow keys. The finished app uses layout, text, keyboard input, live updates,
and explicit cleanup.

## Installation

This guide uses [Bun](https://bun.sh). Create an empty project and add OpenTUI:

```bash
mkdir my-tui && cd my-tui
bun init -y
bun add @opentui/core
```

## Create the app

Create `index.ts`:

```typescript
import { Box, Text, TextRenderable, createCliRenderer } from "@opentui/core"

const renderer = await createCliRenderer({
  exitOnCtrlC: true,
  backgroundColor: "#1131E9",
})

let count = 0
const counter = new TextRenderable(renderer, {
  id: "counter",
  content: "Count  0",
  fg: "#FFFFFF",
})

renderer.root.add(
  Box(
    {
      width: 42,
      height: 9,
      backgroundColor: "#1131E9",
      alignItems: "center",
      justifyContent: "center",
    },
    Box(
      {
        width: 38,
        height: 7,
        backgroundColor: "#2947F0",
        padding: 1,
        flexDirection: "column",
        gap: 1,
        alignItems: "center",
      },
      Text({ content: "Hello, OpenTUI!", fg: "#DCE3FF" }),
      counter,
      Text({ content: "left/right change | q quit", fg: "#AEBBFF" }),
    ),
  ),
)

renderer.keyInput.on("keypress", (key) => {
  if (key.name === "q") {
    renderer.destroy()
    return
  }

  if (key.name === "left") count--
  else if (key.name === "right") count++
  else return

  counter.content = `Count  ${count}`
})
```

`createCliRenderer()` takes control of the terminal and returns the root of the component tree. `Box` lays out its
children in a column. `Text` creates static text, while `TextRenderable` gives the event handler a mutable component to
update.

The renderer emits parsed keyboard events through `keyInput`. The handler changes `counter.content`, which schedules a
new frame.

## Run it

```bash
bun index.ts
```

Press the Left and Right arrow keys. The count updates in place. Press `q` to destroy the renderer and restore the
terminal. `Ctrl+C` also exits because `exitOnCtrlC` is enabled.

## Use the project scaffold

[create-tui](https://github.com/msmps/create-tui) can generate a larger starter project and configure a framework
binding for you:

```bash
bun create tui
```

## Use Node.js

OpenTUI also runs on Node.js. Package imports do not require FFI, but `createCliRenderer()` and other APIs that load the
native Zig renderer require FFI. Use Node.js 26.4.0 with `--experimental-ffi`. If you use Node.js permissions, also add
`--allow-ffi` and the filesystem permissions that your application needs.
