# Getting started

OpenTUI is a native terminal UI core written in Zig with TypeScript bindings.

It renders a component tree, lays it out with Flexbox, handles terminal input, and updates the cells that changed. The
native core exposes a C ABI for other language bindings. OpenTUI powers OpenCode in production.

## Start here

[Build your first app in the quickstart](/docs/getting-started/quickstart). You will create a project from an empty
directory, compose a small interface, handle keyboard input, and run it in your terminal.

The quickstart uses `@opentui/core` directly. The same renderer and components support the React and Solid bindings.

## Choose an API

- [`@opentui/core`](/docs/core-concepts/renderer) uses TypeScript factories, renderables, and events directly.
- [`@opentui/react`](/docs/bindings/react) uses React components, hooks, and state.
- [`@opentui/solid`](/docs/bindings/solid) uses Solid components, signals, and effects.

Start with core when you want direct control or are learning how OpenTUI works. Use a framework binding when your app
already uses that framework or benefits from its state model.

## Find a topic

- [Renderer](/docs/core-concepts/renderer) covers terminal setup, rendering, and cleanup.
- [Layout](/docs/core-concepts/layout) covers Flexbox sizing and positioning.
- [Constructs](/docs/core-concepts/constructs) covers the declarative component API.
- [Text](/docs/components/text) and [Box](/docs/components/box) display and arrange content.
- [Input](/docs/components/input) and [Select](/docs/components/select) accept user input.
- [Testing](/docs/core-concepts/testing) renders apps in memory for assertions and snapshots.

## Explore the examples

Run the OpenTUI example browser without cloning the repository. On macOS, Linux, WSL, and Git Bash:

```bash
curl -fsSL https://raw.githubusercontent.com/anomalyco/opentui/main/packages/examples/install.sh | sh
```

On Windows, download the latest release from [GitHub Releases](https://github.com/anomalyco/opentui/releases/latest).

## Give an agent the docs

OpenTUI includes a skill that teaches AI coding assistants its APIs and patterns. Install it with
[`npx skills`](https://skills.sh):

```bash
npx skills add anomalyco/opentui --skill opentui
```

Add `-g` to install the skill globally for every project. OpenCode uses the same install command.
