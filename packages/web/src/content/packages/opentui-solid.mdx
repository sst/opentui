OpenTUI Solid brings Solid's fine-grained reactivity to the terminal. Components run
once, and signals connect directly to the renderables: a changing value updates only the
property it touches. There is no virtual DOM and no re-render.

```tsx
import { render } from "@opentui/solid"

const App = () => <text>Hello, World!</text>

render(App)
```

The element set mirrors [OpenTUI Core](/packages/opentui-core): boxes with borders and
flexbox layout, styled text, inputs and selects, scroll areas, code and diff viewers,
markdown, and images. Primitives cover keyboard input, paste, focus, resize, text
selection, and animation.

`render()` also adopts an existing renderer, so a Solid app serves over
[SSH](/packages/opentui-ssh) unchanged. Bun runs the JSX directly through a preload
plugin; Node.js runs compiled output.

The [Solid binding docs](/docs/bindings/solid) cover setup on both runtimes, the
elements, and testing.
